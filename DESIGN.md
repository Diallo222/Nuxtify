# Nuxtify Design System

Kinetic concept store — typography as stage craft, full-bleed imagery, magnetic interactions.

## Color

| Token | Value | Use |
|-------|-------|-----|
| `--color-ink` | `#0B0B0B` | Canvas, surfaces |
| `--color-paper` | `#F4F4F0` | Text, primary CTAs |
| `--color-accent` | `#C8FF3D` | Focus, badges, hover ink, progress |
| `--color-ash` | `#8A8A86` | Muted meta |

## Typography

- **Display:** Syne 600–800 — oversized, tight tracking
- **Body:** DM Sans 400–500

## Motion

- Lenis smooth scroll (disabled under `prefers-reduced-motion`)
- GSAP ScrollTrigger reveals: fade or clip-path **mask wipe**
- Pinned horizontal category scrub (desktop)
- Page wipe transitions
- Desktop custom cursor + magnetic CTAs
- Menu open/close staggered choreography
- Cart drawer slide-over

## Radius

Near-zero (`0`–`2px`). Architectural, not pill-heavy.
